## Scope and ownership

A browser recorder and manual editor, plus a backend video engine and separate agent-driven editing workflows.

End-to-end project by Guillermo Angarita / Andesprit.

## An engineering decision

Separate recording and manual editing in the browser from the backend edit-decision-list engine and optional agent workflows.

## Access and source

Web app. Private source. Chrome, Edge and other Chromium browsers.

## Current scope

The public manual editor and the repository’s agent workflows are separate experiences. No account, pricing or never-uploaded promise is made.
