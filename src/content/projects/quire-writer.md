## Scope and ownership

A desktop editor with live document previews, agent chat, inline edits and a review step for changes.

Andesprit project · writing application

## An engineering decision

Keep agent edits pending until the writer reviews them. The app runs the chosen agent through ACP using the writer’s existing login.

## Access and source

## Current scope

macOS Apple Silicon is the primary platform; other platform support is experimental. Some previews and exports need separately installed TeX, Quarto or Pandoc. Agents may send project context to their provider.
